Приложения для расчета характеристик геометрических фигур.

Приложение читает данные из файла shape.txt и выводит результат либо в консоль,
либо в файл.

Во входном файле указываем:

- первой строкой тип фигуры прописными буквами - CIRCLE, RECTANGLE, TRIANGLE

- второй строкой параметры фигуры через пробел
  (у круга - радиус,
у прямоугольника - длина и ширина,
у треугольника - три стороны)

Пример:

CIRCLE

5

или

TRIANGLE

3 3 3

Запуск приложения:

В пакете с jar создаем файл shape.txt, где и указываем необходимые параметры.

Метод вывода: file или console.

java -jar Task2-1.0.jar --input=<путь_к_файлу> --output=<метод_вывода>

Например: java -jar Task2-1.0.jar --input=shape.txt --output=file

Результат будет сохранен в файл result.txt, путь к которому будет указан в логах.

Для запуска из IntelliJIdea в Run Configuration в поле program arguments указываем:

--input=Task2/src/main/resources/shape.txt --output=console

Результат будет выведен в консоль.

Логи приложения выводятся в консоль и в файл shape-application.log
