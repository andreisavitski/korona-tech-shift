Приложение можно запустить напрямую из IntelliJ IDEA:

1. Откройте проект в IntelliJ IDEA
2. Найдите класс MinesweeperApplication
3. Нажмите Run

Все данные о текущих играх и результатах игр сохраняются в проекте в виде сериализованных объектов:

Папка хранения: src/main/resources/dbfile

Файлы:

games.txt - хранит список всех текущих игр

game-results.txt - хранит историю результатов игр
